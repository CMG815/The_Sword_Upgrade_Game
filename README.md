## 프로젝트 개요

이 프로젝트는 게임의 **강화 시스템**을 구현합니다. 플레이어는 아이템 강화를 시도하며 성공과 실패가 확률에 따라 결정됩니다. 주요 기능은 다음과 같습니다:

- **강화 성공/실패** 로직.
- **골드 관리** (강화 비용 차감).
- **장인의 기운 시스템** (실패 시 확률 증가).
- **UI 통합** (강화 상태 및 골드 표시).
- **확률 증가 아이템** (일시적인 성공률 증가).

---

## 주요 기능

1. **강화 시도 로직**

   - 현재 강화 단계에 따른 성공 확률 계산.
   - 강화 비용에 따른 골드 차감.
   - 성공/실패에 따른 강화 단계 및 장인의 기운 업데이트.

2. **장인의 기운 시스템**

   - 실패 시 확률을 높이는 시스템.
   - 최대치 도달 시 100% 성공 보장.

3. **골드 관리**

   - 강화 비용 차감.
   - 확률 증가 아이템 구매 가능.

4. **확률 증가 아이템**

   - 성공 확률을 일시적으로 높이는 아이템 사용 가능.

5. **UI 요소**

   - 플레이어 상태(골드, 강화 단계, 장인의 기운) 실시간 업데이트.
   - 자원 부족, 성공, 실패 메시지 표시.

---

## 실행 방법

1. Unity에서 프로젝트를 엽니다.
2. Unity Inspector에서 UI 요소와 스프라이트를 연결합니다.
3. 모든 씬(e.g., "Start", "upScene", "shop", "end")을 Build Settings에 추가합니다.
4. `EnhancementSystem` 스크립트를 적절한 GameObject에 연결합니다.
5. Play 버튼을 눌러 강화 시스템을 테스트합니다.

## 파일 구조

- **EnhancementSystem.cs**

  - 강화 로직을 처리하는 핵심 스크립트.

- **UI 에셋**

  - 강화 단계를 위한 이미지 및 스프라이트.

- **씬**

  - 시작 씬, 상점 씬, 강화 씬, 종료 씬.
